# mabel.c — portfolio

Static site, no build step. Open `index.html` locally or publish with GitHub Pages.

- `index.html` — home
- `mori.html`, `harbor-freight.html`, `kitbit.html` — project pages
- `playground.html`, `about.html`
- `style.css`, `main.js` — shared styles and interactions
- `img/` — web-sized images

Playground items and the Mori research deck link to the original site at mabelchen.net.
